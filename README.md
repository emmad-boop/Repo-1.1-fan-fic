# FanFiction.net Sources for Shosetsu and LNReader

Community source repository for reading FanFiction.net stories in Shosetsu and LNReader.

## Sources

- Shosetsu: `shosetsu/src/en/FanFictionNet.lua`
- LNReader: `lnreader/plugins/english/FanFictionNet.ts`

FanFiction.net may use Cloudflare protection, so availability can depend on the reader app and network.

## Status

Initial source implementation. Test in the target app before treating it as production-ready.
